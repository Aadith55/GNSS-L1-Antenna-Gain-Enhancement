# Results summary

## Phase 1 — DGS + symmetric patch slots

| Metric | Basic L1 patch | Proposed DGS + slots |
|---|---:|---:|
| Simulated S11 | -19.71 dB | -20.82 dB |
| Simulated peak gain | 2.18 dB | 2.38 dB |
| Simulated -10 dB bandwidth | 1.524–1.560 GHz | 1.540–1.577 GHz |

The paper reports measured S11 of -22.186 dB at 1.632 GHz for the fabricated proposed design. No measured gain value is listed here because the experimental-validation section identifies S11 measurement; the gain values above are labelled as simulated.
