# Native simulation models

Place native electromagnetic simulation project files in the corresponding tool folder:

- `hfss/` — Ansys Electronics Desktop / HFSS projects (`.aedt`).
- `cst/` — CST Studio Suite projects (`.cst`).

The supplied local simulation files have not been uploaded to this GitHub repository yet. Before committing large model files, check whether they depend on companion result folders or external libraries, and remove any private or unnecessary project data. Verify that the project opens in the target software version before treating cached results as reproducible.
